The computed device is not a true SAR mixer

The scalar interface bends and smears, but it does not multiply into four or eight lamellae.

  • one strictly planar flow domain;
  • no out-of-plane branch exchange;
  • top and bottom streams retain their ordering;
  • mixing comes from interface stretching plus physical and numerical diffusion.

Best stored mixing sample 00027. The red/blue interface remains a single ordered transition across the outlet.

Each cell combines a centre baffle with alternating wall bias

The centre plate is continuous across adjacent merge/split segments; the wall-deflector bias is piecewise constant within each cell.

The CFD model is steady, laminar, and convection dominated

Flow

∇·u = 0

(u·∇)u = −∇p + ν∇²u

  • simpleFoam, laminar;
  • ν = 10⁻⁶ m²/s;
  • H = 1 mm, mean inlet speed 0.01 m/s;
  • Re = 10.

Passive scalar

u·∇T = DT∇²T

  • scalarTransportFoam;
  • D_T = 10⁻⁹ m²/s, Sc = 1000;
  • bottom inlet half T=1, top half T=0;
  • bounded Gauss upwind for div(phi,T).

The first-order scalar scheme is robust but can smear the interface far more strongly than molecular diffusion at this cell size.

The goal is a Pareto set, not one “best” geometry

Hydraulic objective

Jdp(θ) = ⟨p⟩in − ⟨p⟩out

OpenFOAM stores kinematic pressure, so the native unit is m²/s².

Physical ΔP in pascals is ρJdp. For water, the observed 0.0010–0.0026 m²/s² corresponds to roughly 1.0–2.6 Pa.

Mixing objective

Jmix(θ) = Is = σ²T,out / 0.25

I_s = 1 preserves the inlet variance; I_s = 0 is uniform.

Optimization: minimize (J_dp, I_s). Plots use 1 − I_s only because higher mixing quality is easier to read.

[Sources] Pressure calculation: ../../src/functionObjects/pressureDrop/pressureDrop.C and ../FlowCase/0/p. Mixing calculation: ../../src/functionObjects/patchMixingQuality/patchMixingQuality.C. Objective column selection: ../bayes_optimize_sequential.py.

The implemented mixing objective is face-count weighted

T̄ = (1/N) Σ Ti

σ² = (1/N) Σ T²i − T̄²

Is = σ² / [0.5(1−0.5)]

The function object also reports flux-weighted mean, variance, and intensity, but BO reads the unweighted intensity_of_segregation column.

This differs from the area integral stated in the original benchmark note.

  • equal weighting per outlet face;
  • sensitive to nonuniform face spacing;
  • not a residence-time or mass-flux objective;
  • should be compared against area- and flux-weighted alternatives.
[Sources] Exact loops and formulas: ../../src/functionObjects/patchMixingQuality/patchMixingQuality.C. Original area-integral claim: ../../docs/obsidian/02-Technical-Notes/Benchmark-Problem-Specification.md. Current objective selection: ../bayes_optimize_sequential.py.

The BO engine maximizes hypervolume in the negated objective space

Surrogate

  • SingleTaskGP(X, −Y) with two outputs;
  • input normalization in seven dimensions;
  • output standardization;
  • exact marginal-likelihood fitting;
  • checkpointed hyperparameters warm-start later runs.

Acquisition

  • qLogNoisyExpectedHypervolumeImprovement;
  • fallback to qNEHVI for older BoTorch;
  • q = 1, 10 restarts, 256 raw samples;
  • reference point = observed worst minus 10% of range;
  • 8 Sobol starts + 20 sequential suggestions.

The optimizer is pressing against design-space boundaries

ws on the upper bound across much of the Pareto front
0.15
δ at its upper bound for most non-dominated designs
15/28
non-dominated points in a small campaign

The campaign identifies a useful trade-off, but it has not demonstrated an interior optimum.

  • thicker centre baffles correlate with worse mixing;
  • larger gaps and wall bias generally reduce both objectives;
  • the best-mixing designs use thin baffles and a negative bias slope;
  • bounds and parameterization now define the next scientific question.
[Sources] Boundary values and the 15-point Pareto set were calculated from ../results/all_samples.csv. Correlation observations are exploratory, not causal: t_s versus Is r≈0.90; t_m versus Is r≈0.88 across 28 samples.

The BO study is useful—once its claim matches its geometry

Call it a Planar Alternating-Deflector Micromixer, report kinematic pressure correctly, and treat the current front as a numerical design study rather than validated SAR lamination.

Immediate validation

  • repeat selected points on refined meshes and higher-order scalar schemes;
  • compare face-, area-, and flux-weighted mixing objectives;
  • add a straight-channel and symmetric-deflector baseline;
  • report physical ΔP after multiplying by density.

If true SAR is the goal

  • introduce separate branches with a demonstrable permutation;
  • use a 3-D crossing/stacking topology or a planar network with distinct outlets/inlets;
  • verify layer multiplication from cross-sectional scalar fields;
  • then re-run BO on the new topology.
