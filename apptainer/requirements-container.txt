# Pinned Python environment for the Apptainer image.

# WHY PINS AND NOT THE RANGES IN PlanarAlternatingDeflectorMixer/requirements.txt:

# are the versions the corrected campaign was produced with locally.

# design against an archived sample) before trusting any new number.
